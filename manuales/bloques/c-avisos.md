La campaña puede mandarte avisos al celular. Para recibirlos como notificación tienes que activarlos en este teléfono; para leerlos completos, entra a «Mis avisos».

## Pasos

1. Toca **Más** y, en «Mi cuenta y ayuda», toca «Mis avisos».
2. Arriba está el interruptor de avisos. Actívalo y acepta el permiso de notificaciones que pide el teléfono.
3. Debajo ves la lista de avisos que has recibido. Toca uno para leerlo completo.
4. Cuando te llegue una notificación, tócala: abre ese aviso.

::: listo
El interruptor queda activado y, cuando haya un aviso nuevo, tu teléfono te avisa.
:::

::: consejo
En iPhone, primero agrega la aplicación a la pantalla de inicio (Compartir → Agregar a inicio) y vuelve a entrar desde ese ícono: si no, el teléfono no permite avisos.
:::
